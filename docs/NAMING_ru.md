# Система именования функций

Для удобства работы с библиотекой функции именуются в соответствии
со следующей системой:

* Функции начинаются со префикса `BRST_`
* Если функция имеет параметр `Doc`, то он должен быть первым.
  Имя дополняется префиксом `_Doc`
* Если функция требует параметра `Page`, он идет первым или вторым, если
  есть параметр `Doc`. Имя дополняется префиксом `_Page`.
* Далее указывается название объекта, с которым работает функция, например
  `_Font` или `_Image`
* В некоторых случаях может использоваться дополнительный суффикс, если
  логика функции того требует:
  `BRST_Doc_Image_Png_LoadFromFile()`
* Последним элементом названия идет действие, если это уместно.

Действие представлено глаголом или признаком &ndash; `Add`, `Use` и пр.
Действие может состоять из нескольких слов. В этом случае они идут подряд
с использованием CamelCase (каждое слово в заглавной буквы).

Если действие явным образом устанавливает какое-то свойство, тогда дейстие
должно начинаться со слова `Set` (`SetCurrent`, например).

Если необходимо получить свойство (как парное к `Set`), то слово `Get`
не используется (`BRST_Font_FontName()`, например).
